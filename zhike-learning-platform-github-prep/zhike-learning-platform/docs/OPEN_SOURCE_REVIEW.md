# 公开发布前必须人工复核

原始项目由用户提供，公开候选版不是安全审计结论，也不是可直接用于生产的系统。

## 已做的整理

1. 移除了 `server/services/llmService.js` 中的硬编码备用API密钥，改从 `ZHIKE_FALLBACK_API_KEY` 环境变量读取，不配置则跳过备用服务。
2. 移除了 `ecosystem.config.js` 和认证模块里的固定JWT秘密，改为启动时要求提供长度至少32的 `JWT_SECRET`。
3. 移除了SQLite初始化时自动创建的**固定密码用户**及随机的示例统计记录，改为可用 `ADMIN_USERNAME`、`ADMIN_PASSWORD` 初始化管理员。
4. 从登录页删除了公开展示固定默认账号/密码的快速填充区块，保留无密钥提示。
5. 排除旧的 `server-bundle.js` 以及第三方 `models/` 权重；均未改动原上传压缩包。
6. 追加 `.gitignore`、`.env.example`、README；保留旧的`setup.sh`为 `docs/legacy-setup.sh.txt`，仅作参考。
